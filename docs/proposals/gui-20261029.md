# P5-U1 控制台优化与验证（2026-10-29）

> 此文记录第一轮改版。当前主机专属 UI、5143 端口和虚拟卡生命周期以 `gui-host-20261029.md`（D17 / P5-U2）为准。

## 结果与范围

`agent/vc-agent.py` 的内置 `/ui` 改为“链路总览”和“连接配置”两个页面，保持单文件、零运行时依赖。复用现有 REST 端点，未改 wire、原生采集/传输、配置字段、API 返回或验收判据。本轮实现已完成，尚未重新打包、发版或部署到实际双机。

## 改动

- 深色控制台，统一字体、图标、状态色与按钮；桌面侧栏和窄屏顶部导航。总览包含四项主指标、双端设备、最近 60 秒分段 p99 曲线、质量计数、操作记录。
- 配置按角色显示，检测网卡复用 `/adapters`；高级传输参数折叠。对端控制台链接在窄屏也可使用。
- 轮询不覆盖未保存的编辑，支持撤销；保存不重启当前采集。运行中更换本机角色须先停播，旧的在途状态请求不会覆盖刚保存的配置。
- 开播前检查已保存配置、双方网卡、互补角色、可达状态与版本；发现本机可达的现有会话时保留停播能力，包括对端失联或配置角色丢失时。
- 离线、停止、缺少指标或桩进程均显示 `—`，真实零值仍显示零。桩进程明确提示“没有真实传输”。帧率在换会话、计数回退、进程重启或长轮询间隔后重建基线。
- 请求有超时，服务恢复后自动重连；诊断信息尽量用中文说明。操作记录最多保留 80 条，仅保存在当前页面，不删除服务端日志。用户内容用 `textContent` 渲染。
