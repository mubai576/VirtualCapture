# Rust GPUI 采集工作台视觉重做（2026-11-14）

owner 要求更精美的 UI，随后要求继续调整主区并过滤本机非物理接收网卡。
本记录保留 Rust-UI1/UI2 的设计过程，并追加 D27 的紧凑布局、OTA入口与原生应用图标；性能判据不改。

## 视觉方向

采用浅银灰工作台与深蓝画幅示意。色彩：雾灰 `#F2F4F7`、白 `#FFFFFF`、深蓝 `#17263D`、
灰蓝正文 `#5D6C80`、操作蓝 `#315CEC`。告警/成功色只表达状态，始终带文字；不作为数据系列配色。
字体：Segoe UI（英文/数字）+ Microsoft YaHei UI（中文），标题28px，主要正文13–14px，辅助说明11–12px。

审视初稿后，决定不只换配色：原来所有参数挤在侧栏、未采集也展示整张空表，是主要阅读负担。
将常用设置移到主区、侧栏只保留设备与预算；保留一处深色输出画幅作为视觉重心，不添加假预览或假曲线。

```text

IP / 连接按钮      输出画幅（非预览）      画面设置

链路预算           运行状态与引导
                   双端详细指标（可展开）
                   最近活动
```

## 主区调整（Rust-UI2）

owner 对画幅与设置区域提出进一步调整。沿用雾灰 `#F2F4F7`、白 `#FFFFFF`、正文深蓝 `#17263D`、
灰蓝 `#5D6C80`、操作蓝 `#315CEC`；字体与辅助文字对比度保持。主标题26px，设置13px，输出规格18px。

审视后移除固定300×388的大画幅卡：配置工作台的重点是设置，静态画幅不需要占据近半主区。
改为一个连续的白色设置面板，标签左对齐、控件逐行对齐；底部仅保留紧凑深蓝输出规格栏，
小画幅仍按比例绘制并声明非实时预览，开始/停止操作紧邻本次输出参数。不给各个参数再套独立卡片。

本机接收网卡同时限制为系统确认的物理设备，空态说明筛选规则；该约束由核心统一执行。

## 交互

- 连接按钮独立一行；Rust-UI2将开始/停止移到设置底部输出规格栏，连接/采集禁用逻辑沿用控制器状态。
- 分辨率/fps/变换/来源改用原生 Button，保留选中、hover、禁用与键盘焦点行为。
- 输出画幅按配置宽高比绘制，只标注格式与目标帧率，明确“画幅示意 · 非实时预览”。
  浮点仅用于 UI 几何，不用于像素生成/采集变换。
- 未采集时显示下一步引导，运行后显示真实指标；双端诊断表可展开/收起，无离线旧数值填充。
- 错误集中在一条带标题的提示中，避免同一错误重复出现在侧栏和主区。
- 画面/设备两侧独立滚动，窗口最小1080×740；默认1280×900。

真实窗口验证通过：720p/120fps点击后持久化、明细展开、1080宽布局、HTTP错误展示及正常关闭。
Clippy/build与51项Rust测试通过，原总闸303 passed / 6 skipped；证据与截图目录见
[Rust 开发记录](../bringup/bringup-20261114-rust-control.md)。

## D27 紧凑工作区与更新入口

按 owner 截图反馈，主区移除“采集工作台”大标题、重复连接引导和整块黄色待清理横幅。
设置面板直接接在应用标题栏之后；待清理原因与重试按钮留在输出操作栏，不隐藏真正阻塞状态。
两端列表统一筛选物理网卡，仍不能用手填隐藏设备绕过核心门禁。

更新入口位于应用标题栏，按需展开本机/被采集机两列，展示当前、待应用版本和历史回滚操作。
ZIP选择、配对、上传与版本切换均触发核心工作线程，状态区显示具体失败原因；不会自动切换已用部署。

应用图标使用深蓝底、取景框与发送箭头，源码为`vc-host/assets/app-icon.svg`。
Windows构建从SVG生成16至256像素ICO并通过rc.exe嵌入PE资源1，覆盖窗口和任务栏，生成二进制仅在OUT_DIR。

运行指标区将到帧间隔、采集转换、发送分段、重组分段和虚拟卡交付各自标注p99，
不合并为含糊的“延迟”数字，不跨机相减QPC。owner反馈增加约10ms仍须现场同配置复现定位。
D27实际验证与未验收边界见开发记录，不继承上节UI1/UI2测试结果。
